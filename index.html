Selected work

Three projects that show breadth.

Chosen because together they span identity, cloud security, and data protection — the three areas where the stakes are highest.

OK
Identity & Access Management · Okta
Enterprise SSO rollout — from 3 days to 4 hours
SCOPE: 1,200 users · 40+ applications · Hybrid on-prem and SaaS
✓ COMPLETED

The organisation had grown through acquisition and ended up with four separate identity providers, manual provisioning, and a helpdesk log full of password resets. The job was to collapse everything into a single Okta deployment — SSO across 40+ apps, SCIM provisioning wired to Workday, and adaptive MFA that worked without creating daily friction for 1,200 users. Existing on-prem AD FS had to stay live throughout the migration while each app was cut over individually.

✓

✓
100% MFA adoption across the organisation within the first rollout week
✓
Login-related helpdesk tickets reduced by 64%

AZ
Cloud Security · Microsoft Azure + Sentinel
Azure security posture lifted from 42% to 87%
SCOPE: All Azure workloads · 2M+ events/day · Ongoing
● ONGOING

The environment had grown faster than the security policies around it — public storage accounts, permissive NSGs, no centralised logging, and a Defender for Cloud Secure Score sitting at 42%. The work was to implement Microsoft Sentinel as the SIEM/SOAR backbone, build detection rules and automated playbooks, enforce Azure Policy across all subscriptions, and remediate the misconfigurations driving the low score — without disrupting the workloads already running.

✓
Defender for Cloud Secure Score improved from 42% to 87% over 90 days
✓
Sentinel ingesting 2M+ events/day with automated triage — MTTD under 15 minutes
✓
Azure Policy enforcing compliance on 100% of subscriptions — zero drift
✓
Cloud misconfigurations reduced 78% in the first month

VB
Data Protection · Veeam Backup & Replication
Backup overhaul — RTO from 4 hours to 22 minutes
SCOPE: 320 VMs · 140TB data · Scale-out with immutable storage
✓ COMPLETED

The existing Backup Exec environment was failing jobs nightly, had no offsite copy, no immutability, and a documented RTO of "around 4 hours." After a near-miss ransomware incident, the organisation needed a full rebuild. Veeam v12 was deployed with a scale-out backup repository, S3 object lock for immutability, WAN-accelerated offsite replication, and a SureBackup lab verification programme that runs automated recovery tests against all Tier-1 VMs every quarter.

✓
Recovery time cut from 4 hours to 22 minutes — validated quarterly via SureBackup
✓
140TB protected with full 3-2-1-1 coverage — immutable copy on S3 Object Lock
✓
$95K storage savings through deduplication and scale-out tier architecture
✓
100% recovery success rate across 8 quarterly DR tests since deployment
Veeam v12SOBRS3 Object LockSureBackupWAN AccelerationVeeam ONE
